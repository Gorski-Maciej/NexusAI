3. AUDYT KSeF (GŁÓWNY PRIORYTET) — KOMPLETNOŚĆ ŁAŃCUCHA
────────────────────────────────────────────────────────────────────────────────
OBOWIĄZEK: od 2026-02-01 dla wszystkich czynnych podatników VAT (z wyjątkiem
zwolnionych). Podstawa: art. 106na-106nb VAT, Dz.U. 2023 poz. 1598.

ŁAŃCUCH KSeF (100% zautomatyzowany):
  GENERACJA XML → WALIDACJA XSD → FIREWALL → WYSYŁKA API → UPO → MONITORING
       │                │             │          │          │          │
       ▼                ▼             ▼          ▼          ▼          ▼
   FA(2) XML      P_1..P_8 OK   anomalie=0  online/    24h alert  sankcje
   z danymi       blokada CI    BLOCK jeśli   offline    TRIAGE    kalkulator
   faktury        na invalid    są anomalie   retry 7d   jeśli brak 500k PLN

GENERACJA XML:
  • Schemat FA(2) — elementarne typy danych, kody krajów ISO, kody walut ISO
  • Pola P_1..P_8: dane sprzedawcy, nabywcy, kwoty, daty, GTU, procedury
  • Walidator XSD offline (INN-06): xmllint/Java JAXB, CI gate z block_on_invalid
  • ksef_xsd_validator sprawdza brakujące pola przed wysyłką

WYSYŁKA:
  • Online: API KSeF (ksef.mf.gov.pl/api), token KSeF, UPO via API
  • Offline (INN-04): tryb awaryjny do 7 dni (art. 106nb ust. 5-6 VAT)
  • Kolejka offline z auto-retry po przywróceniu łączności
  • ksef_offline_queue_enterprise.rego + ksef_resilience_enterprise.rego

UPO (Urzędowe Poświadczenie Odbioru):
  • Tracker INN-02: invoice_count vs upo_received_count
  • Alert 24h — faktura bez UPO → TRIAGE_QUEUE
  • ksef_upo_tracker_enterprise.rego: pełny cykl życia UPO

SANKCJE:
  • Kalkulator INN-03/INN-13: faktury poza KSeF × 1 000 zł (max 500 000 zł)
  • Poziomy: BRAK → UMIARKOWANE (<100k) → WYSOKIE (100k-500k) → KRYTYCZNE (≥500k)
  • ksef_sanction_monitor_enterprise.rego: monitoring w czasie rzeczywistym

SANDBOX:
  • INN-12: środowisko testowe KSeF (ksef-test.mf.gov.pl)
  • Testy integracji przed produkcją
  • ksef_sandbox_harness_enterprise.rego

FIREWALL:
  • INN-07: blokada wysyłki błędnych faktur (anomalie NIP, kwoty, duplikaty)
  • ksef_firewall_enterprise.rego: multi-layer ochrona przed odrzuceniem
  • Integracja z P34 Red Team (adversarial tests)

KOREKTY:
  • Art. 106j VAT: korekty, anulowanie, faktury korygujące
  • ksef_corrections workflow z terminem 30 dni
  • ksef_receipt_digest_enterprise.rego: odbiór faktur kosztowych
