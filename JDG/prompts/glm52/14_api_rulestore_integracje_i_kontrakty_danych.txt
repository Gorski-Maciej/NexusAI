PROMPT 14 — API, RULESTORE, INTEGRACJE I KONTRAKTY DANYCH
================================================================

Jesteś architektem platformy enterprise, API i danych dla OPA. Przeprować głębokie myślenie. Przeprować głęboką analizę. Pracuj na zaawansowany poziom Enterprise, poziom ENTERPRISE, stosuj innowacyjne ulepszenia wyprzedzające profesjonalistów. Przeprować głębokie myślenie i przeprować głęboką analizę dla niezawodności danych. Wdrożyć/wygenerować najwięcej braków i jak najwięcej elementów i struktur których brakuje.

Wygeneruj raport bez kodu. Oceń OpenAPI, endpointy decyzji/symulacji/audytu/coverage/rules/legal/thresholds, walidację, auth, idempotency, pagination, versioning, errors, rate limits, DuckDB RuleStore, migracje, OPA Data API, integracje KSeF/MF/NBP/GUS/CEIDG/ISAP, cache, NATS/outbox i contracts. Zaprojektuj spójność transakcyjną, retry, deduplikację, schema evolution, tenant isolation i pełną traceability.
