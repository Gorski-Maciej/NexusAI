2.8 Firewal VAT/PCC — automatyczne wykluczenie
---------------------------------------------------------------------------

ARCHITEKTURA FIREWALA:

  Wejście: transakcja cywilnoprawna
    ↓
  Czy sprzedawca jest VAT-owcem?
    ↓ TAK → Czy wystawia fakturę VAT?
    ↓ TAK → PCC WYŁĄCZONE (Art. 2 pkt 4)
    ↓ NIE → PCC OBOWIĄZUJE (2%)
    ↓ NIE → Czy transakcja podlega VAT?
    ↓ TAK → PCC WYŁĄCZONE
    ↓ NIE → PCC OBOWIĄZUJE

IMPLEMENTACJA:
  pcc_applies := false { seller_is_vat_payer and vat_rate > 0 }
  pcc_applies := false { transaction_vat_applicable and vat_rate > 0 }
  pcc_applies := true { seller_vat_exempt_subjective }
  pcc_applies := true { not seller_is_vat_payer }

OCENA:
  ✅ Firewal POPRAWNIE zaimplementowany
  ✅ Automatyczne wykluczenie
  ✅ Obsługa: VAT-owiec → brak PCC
