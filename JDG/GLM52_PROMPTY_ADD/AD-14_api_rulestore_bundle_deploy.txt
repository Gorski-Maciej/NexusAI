PROMPT AD-14 — API, RULESTORE DUCKDB, BUNDLE, DEPLOYMENT I ROLLBACK (INFRA RK)
================================================================

Jesteś architektem infrastruktury klasy Enterprise dla silnika reguł OPA + DuckDB.
Przeprować głębokie myślenie. Przeprować głęboką analizę. Zapewnij zaawansowany
poziom Enterprise, poziom ENTERPRISE, innowacyjne ulepszenia wyprzedzające
profesjonalistów. Przeprować głębokie myślenie i przeprować głęboką analizę API,
RuleStore, bundle, deployment, rolling update i rollback. Wdrożyć/wygenerować
najwięcej braków i jak najwięcej elementów i struktur których brakuje.

ZADANIE — ZA AWANSOWA INFRASTRUKTURA DECYZYJNA
1. API (Litestar, OpenAPI): 17 endpointów, JWT, rate limiting (120/60 req/min),
   readiness `/jdg/ready`, health, walidacja wejścia, kody błędów.
2. RuleStore DuckDB: schematy, migracje 001–013, seed progów, hot reload
   (OPA Data API), wersjonowanie.
3. Bundle OPA: budowa (bundle.sh), manifest, sygnatura, verify-before-serve,
   rollback, canary.
4. Deployment: rolling update, zero-downtime, DR, chaos (kontrakt AD-15).
5. Security: JWT, RBAC, szyfrowanie, audit, RODO.
6. Spójność bundle vs `JDG/rules` vs `policies/` (synchronizacja, hash-parity).
7. Obserwowalność deploymentu (health, ready, wersje).
Przeprować głębokie myślenie o tym, jak bezpiecznie i sprawnie dodawać/usować
reguły bez przestojów, przy zachowaniu kontroli wersji i możliwości natychmiastowego
rollbacku (to jest serce wymogu "OPA jako SYSTEM").
