#1: DYNAMICZNE OGRANICZENIE GRANIAN WORKERS + DUCKDB MEMORY LIMIT
===============================================================================

ZYSK:      -0.4 do -0.8 GB RAM  |  DYSK: 0 GB
KOSZT:     30 minut | RYZYKO: Minimalne (zmiana konfiguracji)
PLIKI:     server.py, database.py

PROBLEM:
  - Granian domyslnie 4 workers * ~125 MB = 0.5 GB RAM
  - DuckDB domyslnie uzywa 80% dostepnego RAM (na 8 GB = 6.4 GB na OLAP!)
  - Na dev (1-2 rdzenie) wystarczy 1-2 workers

ROZWIAZANIE:
  1. server.py: dynamiczne `workers=max(1, cpu_count()-1)`
  2. database.py: `PRAGMA memory_limit='512MB'`
  3. W dev: `workers=1`

IMPLEMENTACJA:
  server.py:
    import os
    workers = int(os.getenv("NEXUS_GRANIAN_WORKERS", max(1, os.cpu_count() or 2) - 1))

  database.py (przy inicjalizacji DuckDB):
    conn.execute("SET memory_limit = '512MB'")
    conn.execute("SET threads = ?", (max(1, os.cpu_count() or 2) - 1,))

ZYSK: -0.4 do -0.8 GB RAM

#2: LAZY LOADING MODELI AI (GGUF + OCR)
===============================================================================

ZYSK:      -0.8 do -3.0 GB RAM  |  DYSK: 0 GB
KOSZT:     2-4 godziny | RYZYKO: Niskie
PLIKI:     core/inference.py, services/vision/agent.py

PROBLEM:
  - Model LLM GGUF (~800 MB - 3 GB) ladowany przy starcie workera
  - Modele OCR ladowane wszystkie na start
  - RAM marnowany przez caly czas zycia procesu, nawet gdy AI/OCR nie jest uzywane

ROZWIAZANIE:
  1. Lazy loading: `_model: ModelType | None = None`
  2. Getter: `def get_model(self) -> ModelType: if self._model is None: self._load()`
  3. Cache z TTL: automatyczne zwalnianie po okresie bezczynnosci
  4. Unload: reczne zwolnienie modelu gdy niepotrzebny

IMPLEMENTACJA (core/inference.py):
    class ModelManager:
        _model: Any | None = None
        _loaded_at: float = 0
        _ttl: int = 300  # 5 minut

        async def infer(self, prompt: str) -> str:
            model = await self.get_model()
            return await model(prompt)

        async def get_model(self):
            if self._model is None or (time.time() - self._loaded_at) > self._ttl:
                await self._unload()
                self._model = await self._load()
                self._loaded_at = time.time()
            return self._model

        async def _unload(self):
            if self._model is not None:
                del self._model
                gc.collect()
                self._model = None

ZYSK: -0.8 do -3.0 GB RAM (przy braku zadan AI)

#3: REDUKCJA SILNIKOW OCR Z 4 DO 2
===============================================================================

ZYSK:      -0.5 do -1.5 GB RAM  |  DYSK: -0.5 GB
KOSZT:     1-2 godziny | RYZYKO: Niskie
PLIKI:     pipeline/ocr_consensus.py, pyproject.toml

PROBLEM:
  - Projekt uzywa 4 silnikow OCR: Tesseract + PaddleOCR + docTR + EasyOCR
  - Kazdy utrzymuje swoje modele w pamieci
  - Konsensus 4 silnikow daje marginalna poprawa jakosci vs 2 silniki
  - PaddlePaddle: ~600 MB na dysku, ~0.5 GB RAM
  - docTR: ~200 MB na dysku, ~0.3 GB RAM
  - EasyOCR: ~100 MB na dysku, ~0.3 GB RAM

ROZWIAZANIE:
  1. Zostawic: Tesseract (lekki, szybki) + PaddleOCR (najdokladniejszy)
  2. Wyłączyc: docTR + EasyOCR przez konfiguracje
  3. Konsensus = majority voting z 2 zamiast 4

IMPLEMENTACJA (pipeline/ocr_consensus.py):
    # W konstruktorze:
    ACTIVE_ENGINES = os.getenv("NEXUS_OCR_ENGINES", "tesseract,paddleocr").split(",")
    # LUB
    active_engines = config.get("ocr_engines", ["tesseract", "paddleocr"])

#4: ONNX RUNTIME ZAMIAST PADDLEPADDLE
===============================================================================

ZYSK:      -0.3 GB RAM  |  DYSK: -0.45 GB
KOSZT:     4-8 godzin | RYZYKO: Srednie (wymaga konwersji modeli)
PLIKI:     pipeline/ocr_consensus.py, pyproject.toml

PROBLEM:
  - PaddlePaddle to najwiekszy pojedynczy pakiet: ~600 MB na dysku
  - Wymaga calej biblioteki deep learningowej tylko dla OCR

ROZWIAZANIE:
  1. Konwersja modeli PaddleOCR -> ONNX (przez paddle2onnx)
  2. ONNX Runtime ~150 MB zamiast 600 MB
  3. Obsluga quantyzacji INT8 -> kolejne -50% RAM podczas inference

IMPLEMENTACJA:

        def __init__(self):

    # "onnxruntime>=1.17.0",
